# Overview

Adefam Online Learning Platform is a Django web app that allows users to view, search, and select online courses. Course information is stored in MongoDB and dynamically displayed by Django.

Start the server with:

```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in a browser.

The purpose of this project is to practice building server-side web applications with Django, Python, and MongoDB.

[Software Demo Video](http://youtube.link.goes.here)

# Web Pages

* **Home Page:** Displays courses from MongoDB and allows users to search for courses.
* **Course Detail Page:** Displays information about a selected course. Users can return to the Home Page.
